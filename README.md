## 🛡️ Universal Backup & Restore System — Total Data Sovereignty

Located at `#/backup`, the Universal Backup & Restore System provides full, self-sovereign custody over notes, tasks, expenses, habits, goals, calendar items, preferences, and custom tool storage:

1. **Dashboard & Storage Analytics:** Real-time KPI summary cards displaying Last Backup Date, Total Stored Records, Estimated Archive Size, and Storage Health across both IndexedDB and LocalStorage.
2. **Universal JSON & ZIP Backups:** Export complete application data in standardized JSON with SHA-256 integrity checksums or in all-in-one ZIP bundles with spreadsheet exports and human-readable plain text documentation (powered by a pure TypeScript, zero-dependency PKWARE ZIP engine).
3. **Granular Category Selection:** Toggle inclusion for My Notes, My Tasks, My Expenses, My Habits, My Goals, My Calendar Events, Bookmarked Tools, Recently Used, Settings, and Custom Tool Data.
4. **AES-256-GCM Password Encryption:** Optional military-grade password protection using PBKDF2 (100,000 rounds, SHA-256) and AES-256-GCM authenticated encryption via the W3C Web Crypto API. 100% client-side with zero server storage.
5. **Multi-Stage Restoration Pipeline:** Pre-restore inspection and validation engine with structure checks, SHA-256 verification, and conflict detection. Supports 3 restoration modes:
   - **Safe Merge:** Preserves existing records and re-keys conflicting IDs automatically to guarantee zero data loss.
   - **Replace & Overwrite:** Wipes selected local collections and replaces with archive data after explicit user danger confirmation.
   - **Selective Restore:** Selectively restores only desired categories.
6. **Tabular & Readable Formats:** Fast one-click downloads for Expenses CSV, Tasks CSV, Notes CSV, Habits CSV, and human-readable TXT markdown summaries.
7. **History & Configurable Reminders:** Local history log of previous exports and automated reminder schedules (Weekly, Monthly, Manual) with subtle alert banners when backups are due.

## 🛠️ Technology Stack

- **Framework:** React 18.3 + TypeScript 5.7
- **Build System:** Vite 6
- **Styling:** Tailwind CSS 3.4
- **Icons:** Lucide React (Tree-shaken dynamic icon mapper)
- **Document & PDF Processing:** Browser-native `@media print` vector engine + `pdf-lib` (100% in-browser client-side PDF manipulation)
- **Local Cryptography:** Web Crypto API (SubtleCrypto: AES-GCM, PBKDF2, SHA-256, SHA-512) + Client-side RFC 1321 MD5
- **Audio Processing & Recording:** W3C Web Audio API (`AudioContext`, `OfflineAudioContext`, `decodeAudioData`, PCM RIFF/WAVE encoder) + MediaRecorder API
- **Video & Animation:** HTML5 `<video>`, Canvas 2D captureStream, pure TypeScript GIF89a LZW encoder
- **Image Processing:** HTML5 Canvas API + File API + Blob API

## 📦 Getting Started

### Prerequisites

- Node.js >= 18.0.0
- npm >= 9.0.0

### Installation

```bash
# Clone the repository
git clone https://github.com/officialhazim42/lifetools.git

# Navigate into project directory
cd lifetools

# Install dependencies
npm install
```

### Development Server

```bash
npm run dev
```

Visit `http://localhost:5173` in your browser.

### Run Tests

```bash
npm test
```

### Production Build

```bash
npm run build
```

The optimized static production output is generated in `./dist`, alongside an automatically updated `public/sitemap.xml` containing all 684 platform URLs.

## 🌐 Deployment (Surge.sh)

LifeTools is pre-configured for production hosting on **Surge.sh** at **`lifetools.surge.sh`**:

1. **Authenticate with Surge (one-time):**
   ```bash
   npx surge login
   ```
2. **Build and Deploy:**
   ```bash
   npm run deploy
   ```
   *This automatically runs `npm run build`, generates `dist/200.html` for zero-404 client-side SPA routing, verifies `dist/CNAME` (`lifetools.surge.sh`), and publishes to Surge.*

See [DEPLOYMENT_GUIDE.md](file:///c:/Users/DE/.gemini/antigravity/scratch/lifetools/DEPLOYMENT_GUIDE.md) for full instructions and post-deployment verification.
